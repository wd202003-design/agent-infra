# 0006：D1 数据路径与硬预算落地边界

状态：接受；实现不等于真实环境认证。

- 工作区 ID 必须同时出现在用户授权、不可变策略、节点注册策略和节点本地管理员映射中。原始路径不出现在公共协议。目录按 fd + O_NOFOLLOW 读取，拒绝硬链接、设备、跨挂载和复制期间变更；每个 attempt 创建独立快照，OpenSandbox 按只读 Volume 挂到 `/workspace`，独立 verifier 校验源路径与只读状态。
- private 仅允许运行管理员发布的固定 program；不调用中央模型，不上传 stdout/stderr/原始产物。结果只保留在节点私有目录，中央仅返回固定完成提示和状态。
- edge_summary 只允许内置 `numeric-jsonl-v1` 聚合；列/范围/最小样本量由本地管理员配置。动态 Agent 只挂载 `summary.json`，不能挂原始目录。中央校验聚合 schema、摘要以及隔离证明；日志采用元数据白名单。
- hard 预算依赖管理员审核的计费证明记录：固定模型/价格版本、byte-fallback tokenizer 与消息模板的经验证上界、全部输出计费 Token 受参数上限限制、无额外计费项及证明期限。代码不把任意兼容 API 当作具备上述性质。预占最坏成本，实际违反上界时记录真实账单、阻断后续路由并进入核对。
- 元数据 90 天后变为最小 tombstone；已结算账本/审计 365 天后清理，未知费用和未停止资源不因保留期自动消失。凭证响应密文按票据/轮换窗口销毁。恢复继续重放删除账本和失效旧凭证。

正式开放前仍需对实际 Linux/OpenSandbox、对象存储和供应商计费契约进行验证；没有证明或映射时拒绝准入，不静默降低权限。
