# 模型、产物、事件与 Web

适用：CT-05/06、CP-07/08、WB-01～07、DP-06。模型上游与对象存储都是外部系统，不与业务数据库假定原子提交。

## 模型额度和费用账本

内置 model-access 接受任务级授权，不接受用户传入 URL/key/model 路由。管理员配置 model_alias → upstream_id/model/version/price_version/quota_pool_id；同一供应商账户共享额度的多个 key 必须属于同一池。1～2 个上游只做显式路由；结果未知时不得切换上游重发。

请求键为 (task_id,attempt_id,step_id,request_id)，重复且摘要相同返回首次已完成结果；pending/unknown 返回状态和核对引用，不能第二次发给上游。先在 PG 事务中锁额度池与任务预算，预留并发/RPM/TPM/费用，提交后再调用上游。响应/实际用量落库后结算，未知则保留预留并进入核对。

实际加锁遵守统一顺序：先 task，后 quota_pool；多个池按 ID 排序，不从池反向锁任务，避免与领取/终态事务死锁。

费用使用整数微货币单位（micro-CNY 或 micro-USD），不使用浮点，跨币种不自动换算。保存价格版本、输入/输出/缓存 token、估算费用、上游核对费用及差额追加分录。预算区分 token_limit、money_limit、enforcement=hard/soft；UI 必须原样显示性质。

hard 仅对可界定价格和最大请求用量的上游启用：使用该模型 tokenizer 或经验证上界计算输入，锁定 max_output_tokens 和计费项，预留最坏成本；不支持的隐藏/额外计费项直接拒绝 hard，不能默默降级。soft 允许估算但达到阈值停止新请求，已经在途费用仍记账。预留到实际结算差额不可负数回绕；actual 超出上界记异常并阻止新调用，不改写真实成本。

对明确未执行/未计费的 429 等暂态拒绝可在网关层重试，最多 3 次，总等待 60 秒，基数 1 秒指数退避、全抖动、遵守 Retry-After，所有次数共用逻辑请求与累计预算。不能证明未执行的超时、连接中断、响应解析失败一律 unknown；不放大并发、不中途换 key 逃避额度。Workflow 不再重试这一层模型调用。

共享额度存储不可用时暂停新请求；默认池 2 并发/20 RPM/200000 TPM，仅是初始配置，发布前必须不高于实际账户限制。用量未知保留账目和并发占用，管理员查上游账单后以证据追加核对记录；不能凭时间过期自动记零。公开模型错误只含稳定 code/request_id，不返回 SDK 原始请求或密钥。

## 产物对象生命周期

元数据在 PG，内容在私有 S3 API bucket。单文件 20 MiB、单任务 100 MiB、最多 20 个；允许 JSON/text/CSV/PNG/PDF，HTML 必须作为附件下载，不在控制台源站执行。Runner 只能上传 manifest 列举且通过数据出口策略的文件；禁止 socket、设备文件、符号链接和任意宿主路径。

流程：Runner 准备 manifest（相对名、media_type、size、sha256）→ 控制面创建 staging upload_session → 对单一随机 object_key 签发 5 分钟上传 URL → Runner 上传 → complete 请求 → 后台校验 size/checksum/归属 → committed。超过限额、摘要不符、旧 epoch、授权失效均不提交，staging 定时回收。

预签名 URL 在到期前可能复用，不能当作一次性票据。上传只写 staging key；校验后服务端复制到不对 Runner 授写权限的 final key，并固定 object version（若存储支持）。不支持版本的实现必须对 final key 施加写一次/不可替换策略并验证；不能下载可被复用上传 URL 覆盖的对象。记录 SHA-256，ETag 不当成通用内容校验和。

复制读取固定 staging version；无版本能力时采用条件复制防止源替换，并在最终对象上重新校验 size/SHA-256 后才提交元数据。若后端缺少这些能力则拒绝启用文件产物，不能只验证复制前的 staging 对象。

GET 产物先校验 owner/角色/策略/删除状态，再签发最多 60 秒下载链接（敏感产物经鉴权代理下载）。签发记录与链接不写普通日志；撤销后不再签新链接，已发 URL 最长暴露窗口 60 秒，需立即撤销的场景使用代理，不声称 bearer URL 能瞬间作废。产物没有 committed 不能使任务成功；必需产物上传失败可以重试同一会话或新 staging，不重跑外部任务。

## 事件与游标

关键事件与状态同事务。控制面给 task_seq，Runner 补传按 (attempt_id,runner_seq) 去重；同键不同内容拒绝。gap 写可见缺口，不把后来到达的日志用于修改任务状态。过期 epoch 的日志只进入 attempt 审计，不进入当前结果视图。

事件页默认 50、最大 100，`cursor={task_id,last_seq,retention_generation}` 经服务端签名；断线重连从 last_seq 补读。游标超出保留区间返回 410 cursor_expired，附 snapshot URL 和当前最小 sequence，UI 显示历史已过期。查询权限和分页都在服务端执行。

## 页面流程与异常

提交页选择不可变 Agent、允许池/工作区与参数，展示权限摘要、时间/步骤/资源、token 与费用预算性质；提交前生成幂等键，同一网络未知请求不得换键。列表显示排队原因、时限和是否持槽；详情按 attempt 分隔，Demo、估算、费用待核对显式标记。

取消页只报告“已保存请求”；收到停止和清理证据才显示完成。needs_review 页列未知资源/用量/副作用、证据及管理员核对表单；不提供无证据强制成功或一键重放。重新执行创建关联的新任务并重新准入，旧账目不能丢。

日志/文件名/模型文本使用纯文本，HTML 产物附件下载或独立隔离源预览；短期下载 URL 不暴露到 Referer。认证失效清空页面敏感视图，重新登录后按任务 ID 查状态，不自动提交。429 显示 retry_after 和等待上限，503 表明依赖不可用；键盘/焦点/读屏状态提示纳入验收。

节点页管理员管理注册票据、轮换/吊销、信任/能力/槽位与排空；排空不终止在途任务。用量页分别显示已用、预留、未知、估算和核对值；网关未配置不显示“费用为零”。普通使用者不能访问组织管理审计或他人账目。

## 保留、删除和审计

默认任务元数据 90 天，事件/产物 30 天，最小幂等 tombstone 90 天，管理审计/费用账本 365 天，备份 30 天。任务输入/输出属于内容数据，不随审计长期保存；审计仅保留必要身份/摘要/操作证据，不包含完整源码、prompt 或秘密。

终态任务允许 owner 请求内容删除，立即撤销新访问，24 小时内删除线上内容/对象并留下无内容 tombstone；运行/待核对任务先停止与核对，不能删掉资源归属。备份中已删除内容最多残留 30 天，恢复后先重放删除账本再开放访问。需要不同保留期的业务必须在接受数据前配置，不能承诺已从既有离线备份即时抹除。
