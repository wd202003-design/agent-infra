# web：控制台需求

D1 完整目标细节见 [设计基线](../docs/design/data-model-web.md)；当前代码支持范围仍按实现状态记录。以下原始需求继续作为验收依据。

状态：本目录已有独立静态控制台，由正式控制面在 8766 端口提供；包含 Agent 选择、角色访问、任务/用量与节点管理。旧开发界面仍在 devserver/static。真实浏览器自动化与剩余功能见 [实现状态](../docs/implementation-status.md)。

## 页面与操作

| 页面 | 使用者可见内容 | 管理员附加能力 |
|---|---|---|
| 提交任务 | Agent 固定版本、参数表单、可用执行池、权限摘要、预算与时限 | 注册/停用 Agent 版本、配置可用策略 |
| 任务列表/详情 | 状态、排队原因、attempt、事件、结果、产物、取消 | 查看组织授权范围内任务及核对入口 |
| 节点 | 有权使用的池与可用性 | 注册、吊销、排空、能力和槽位配置 |
| 用量 | 自己任务的 token、估算/实际费用、待核对量 | 额度池配置与全局等待原因；不回显密钥 |

## 需求与验收

| 编号 | 阶段 | 要求与验收 |
|---|---|---|
| WB-01 | M1 | 根据固定 Agent schema 生成输入与校验；首次提交生成幂等键，网络未知时复用键查回；双击/刷新不重复创建任务 |
| WB-02 | M1 | 任务详情区分 queued/running/waiting/cancel_requested/needs_review/终态；显示实际等待与停止未知原因，不用进度动画伪造步骤完成 |
| WB-03 | M1 基础 / M3 补传 | 事件有分页/续读、截断与缺口提示；产物下载服务端鉴权；任务输出当纯文本处理，HTML/脚本不执行 |
| WB-04 | M1 | 取消操作显示已收到请求，收到停止与回收确认后才显示完成；终态取消返回当前状态；重复点击无额外副作用 |
| WB-05 | M1 单任务 / M3 额度 | 显示预算性质、已用量、预留与未知量；未接入模型显示“不适用”，不以零费用暗示已对账；Demo 始终醒目标记 |
| WB-06 | M2 / M3 | 管理操作按角色展示且由服务端判权；核对须输入证据/原因；节点排空不等于取消当前任务；操作可审计 |
| WB-07 | M1 | 键盘可完成提交/取消/下载；表单错误关联字段；断网、认证过期、429、空状态和过期游标均可理解且可恢复 |

## 交互边界

提交成功后显示持久化任务 ID。HTTP 超时展示“提交结果待确认”，不能立即建议换键重试。取消文案说明已发出的外部动作不能自动撤回；这是取消操作的实际语义。

正式认证与会话存储随鉴权 ADR 决定；不把开发共享令牌直接升级为多用户登录方案。日志、产物名称、模型内容均按不可信输入呈现；产物预览使用隔离方式，不在控制台源站执行用户生成网页。

Web 只调用版本化契约，不直连数据库、模型上游或沙箱管理端。轮询/流式方式可选，但断线恢复必须遵守事件游标语义；费用估算不得标成正式账单。

## 验证交付

在真实浏览器记录：提交至产物、重复提交、取消竞态、断网重连、越权和恶意日志文本。开发版 JS 语法通过不等于 UI 验收通过；当前浏览器自动化仍未运行。
