# deploy：环境与运维需求

状态：正式部署文件待选型后实现。现有开发启动只使用 [devserver 说明](../devserver/README.md)；真实沙箱准备见 [PoC](../poc/sandbox/README.md)。本文不提供尚未存在的启动命令。

## 环境划分

| 环境 | 依赖与用途 | 交付边界 |
|---|---|---|
| development | 单进程 Python/SQLite/Demo | 本机开发，非公网或多用户服务；不作为真实性能证据 |
| sandbox-test | 受控 Linux 测试宿主、对应沙箱服务、浏览器镜像/模板 | 验证真实执行和隔离；Cube 先确认 KVM/嵌套虚拟化等宿主条件 |
| server | 正式控制面、选定引擎/网关、PostgreSQL、对象存储、服务端 Runner | TLS、节点身份、管理面网络隔离和备份 |
| local / edge | 同协议 Runner、受支持本机 OS 或受管 Linux | 主动出站；绑定工作区/数据位置；在线中央调度 |

## 需求与验收

| 编号 | 阶段 | 要求与验收 |
|---|---|---|
| DP-01 | M1 | 依赖版本、镜像摘要、模板要求和配置 schema 固定；干净宿主按说明启动真实单任务链路 |
| DP-02 | M1 基础 / M2 节点 | 密钥通过环境/秘密管理注入，不进 Git/镜像/日志；管理 API 认证、跨主机 TLS、出入站边界有实测拒绝证据 |
| DP-03 | M1 / M3 | 分离存活与就绪；数据库、协调器或额度服务异常时拒绝对应新工作；输出脱敏指标和 request/task/attempt 关联 |
| DP-04 | M3 | 维护沙箱归属、TTL、孤儿扫描和人工核对 runbook；控制面重启可查回任务和资源，不自动重放未知写入 |
| DP-05 | M4 | PostgreSQL/对象存储备份恢复、数据库迁移、兼容发布与回退演练；先冻结 RPO/RTO 再测试，报告实际恢复时间和损失范围 |
| DP-06 | M4 | 日志/产物保留期限、删除、备份残留及授权过期规则明确；容量/磁盘/孤儿资源告警有处理步骤 |

## 配置契约待实现

配置必须包含环境、服务端地址、凭证来源、数据库/对象存储、节点身份/池、沙箱模板、资源上限、任务/租约/工具时限、事件缓冲限额、模型额度池、保留策略。服务端校验必填字段和范围，缺失安全策略时不能自动改成无限制运行。

配置样例只含占位值；secret 字段禁止在 `/info`、启动日志或健康端点回显。任务不能覆盖沙箱管理 URL、镜像来源、宿主挂载或网关上游凭证。

## 运维交付顺序

1. 沙箱测试宿主清单与证据：真实执行、资源/网络/文件限制、进程树停止、宿主回收、输出洪泛。
2. 单任务开发部署：依赖检查、最小配置、版本锁定、启动/停止/卸载说明。
3. 节点加入/吊销/排空、断网恢复、残留沙箱核对、配额异常处理。
4. 发布迁移与回退、备份恢复、数据删除、容量报告。

CubeSandbox 管理认证须验证服务端实际拒绝无凭证请求，不能只设置 CUBE_API_KEY。PVE 场景先用隔离测试 VM 验证，不修改宿主生产配置。快照恢复不能回滚浏览器或外部系统已发生的写入。
