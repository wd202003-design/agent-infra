## 容量口径

| 指标 | 目标 | 测量规则 |
|---|---|---|
| 真实节点 | 10～20 | 覆盖 server/local/受管 Linux edge；记录每台资源和实际执行能力 |
| 真实任务并行 | 100 | 代码/Shell/浏览器代表混合负载，统计真正执行重叠而非队列或连接数 |
| 活跃任务 | 1,000 | 分别报告 queued/running/waiting/cancel_requested/needs_review 数量；需人工处理也占未完成任务容量，终态单列 |
| 模拟 Runner | 1,000 连接 | 独立测试注册/心跳/断线恢复；不充当真实节点或执行能力 |
| 领取延迟 | P95 ≤ 3 秒 | ready 到 claim，限合格空闲资源且额度满足；同时报告整体排队延迟和被排除样本 |
| 稳定性 | 连续 24h | 已接受任务无丢失，状态恢复和资源残留有核对；无未知副作用自动重放 |
| 模型能力 | 按真实账户配额 | 单列模型并发、RPM/TPM、429、等待时间和成本；不与任务并发混同 |

容量指标是目标。测试前冻结负载比例、任务时长/步骤/输出分布、并行持续时间、样本数、成功率/错误率门槛和成本上限。测试结果不能反向决定通过标准；若范围调整须更新 MVP 并说明原因。

## 每次运行的证据模板

报告至少包含：日期、commit、需求/用例编号、环境和节点清单、组件/镜像/模板/模型版本、脱敏配置、负载定义、命令、预期与实际、样本数、时序/资源/费用、关键事件与产物校验和、宿主回收证据、结论和限制。结果枚举为通过、失败、未运行；环境不具备记“未运行”。

产物放入受控测试存储，仓库只放脱敏摘要和可访问引用；不得上传凭证、私人源码、浏览器登录态或原始边缘数据。任何通过结论要注明是真实后端还是 mock。

## 退出门槛

模块设计完成不等于功能完成。所有对应阶段用例有证据才能退出里程碑。授权逃逸、已接受任务丢失、旧代次覆盖结果、未知外部写自动重试或假取消属于阻断项。容量未达标或真实后端未运行，不能声明完整 MVP 已交付。
